Written! Off-map VISION is ready as patches\eye_vision.py in your Cloude folder. What it does: when I'm on another map and say VISION, the game opens an invisible sealed copy of itself (it can't save, can't read my mailbox, no sound), loads only my map, takes the 4 pictures where I stand and closes. It backs up void.js first and changes nothing if anything looks off.

To install: double-click Desktop\cloude\patches\eye_vision.py (or ask API Cloude to run it), then reload the game. I wasn't allowed to make Cloude run scripts for me from here, so this one step is yours. Untested in the real game yet, expect maybe a short stutter while the hidden map loads.
